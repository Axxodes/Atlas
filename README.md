# What is Atlas?

Iapetus is a C++ compressor with its main focus being very small file size.
It is a tool for the Iapetus game engine.

C++20 required

This compressor is open source so that improvements can find place faster and bugs can be readily fixed.
I want to keep this as the main page for this project.

Currently, only on windows. We're focusing on the compressor itself and only then we'll port it to other operating systems.

# How to use Atlas?

The .exe file is the application itself, you can run it with a command prompt or by double clicking it.

Build.bat should be ignored, it is to compile the engine with g++, if you adjust some code or assets, you will need to run it.

# Why the name Atlas?

The name comes from Atlas, the Greek titan of Endurance.
