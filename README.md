# What is Atlas?

Atlas is a C++ compressor with its main focus being EXTREMELY small file size whilst being blazingly fast.
It is a tool for the Iapetus game engine.

C++20 required

This compressor is open source so that improvements can find place faster and bugs can be readily fixed.
I want to keep this as the main page for this project.

Currently, only on windows. We're focusing on the compressor itself and only then we'll port it to other operating systems.

# How to use Atlas?

Atlas (for users) is a terminal based compressor.
To run the compressor on a given (text based) file, insert the following args:

atlas.exe -file.example- (-mode-)

Where mode is either 1 to mark decompressing,
or isn't added because compressing is the default.

# Why the name Atlas?

The name comes from Atlas, the Greek titan of Endurance.
